# Caminantes — WoW Forever

Addon comunitario de profesiones y pedidos para Caminantes de Azeroth, desarrollado por SotaKun.

## Español

Caminantes es un proyecto gratuito y no comercial para coordinar la fabricación de objetos, compartir catálogos de recetas, gestionar pedidos internos y detectar recetas pendientes en la hermandad.

### Integración prevista con ForeverDB

Utilizaremos los datos de profesiones y recetas de [ForeverDB.net](https://foreverdb.net) para crear un catálogo local de recetas y sus fuentes de obtención: instructores, vendedores, misiones y botines. Compararemos los datos con las recetas conocidas por los miembros de la hermandad.

Los datos se descargarán fuera del juego y se incluirán en las versiones del addon. Identificaremos las fuentes confirmadas en Forever y las procedentes de Classic. Respetaremos los límites de la API, mostraremos la atribución correspondiente y nunca distribuiremos claves de API.

## English

Caminantes is a free, non-commercial guild addon for World of Warcraft Forever. It helps members share profession catalogs, manage crafting orders and discover missing recipes.

### Planned ForeverDB integration

We intend to use [ForeverDB.net](https://foreverdb.net) profession and recipe data to build an offline catalog of recipe IDs, localized names, trainers, vendors, quests and drops. The addon will compare this catalog with recipes known by guild members.

Data will be retrieved outside the game and bundled with releases. We will distinguish confirmed Forever sources from Classic data, respect API limits, visibly credit ForeverDB.net and never distribute API keys.
